# Mac 连接安卓真机：首轮验证清单

更新：2026-11-16。只执行设备接入与页面观察，不触发订单。每步在本地记录结果和时间，不保存手机号、验证码或完整证件信息。

1. 使用那台**已经成功登录大麦 App** 的实体安卓手机。先人工打开一场非热门演出的详情，记录当前 App 版本；不要为验证 USB 连接而重装、清除数据或退出登录。若当前手动状态已异常，先停止连接试验。
2. 使用可传数据的 USB 线连接 Mac。手机“设置 → 关于手机”连续点击版本号开启开发者选项；打开 USB 调试。手机弹出此电脑调试授权时由用户本人确认。
3. 从 [Android 官方 Platform-Tools](https://developer.android.com/tools/releases/platform-tools)下载 Mac 版 `adb`，或经可信包管理器安装。只装平台工具，不装模拟器和系统镜像。
4. 运行 `adb devices -l`。预期只有一台设备且状态为 `device`；`unauthorized` 表示手机端授权未完成，空列表先检查线缆和 USB 模式。记录系统版本和手机型号，不记完整设备序列号。
5. U1 在线和原登录态确认后，如需电脑上查看屏幕，从 [scrcpy 官方仓库](https://github.com/Genymobile/scrcpy)安装并连接。确认鼠标能点击、Mac 键盘可输入，手机仍可直接人工接管。设备多于一台时明确指定序列号。
6. 在手机上人工进入目标演出页面。仅在屏幕不含敏感信息时采集截图与控件层级；含手机号、姓名、证件、订单号的材料先脱敏，放在 `pagesamples/`（不入 Git）。
7. 结束后关闭调试或撤销授权；如需保留供下一次测试，由用户自行决定。无线调试只在 USB 首轮成功后单独测试。

记录模板：日期时间、设备型号、Android 版本、大麦版本、连接状态、登录状态、页面可读性、异常形态、下一步。这里的“真机”始终指用户手中的实体安卓手机；雷电云手机需按独立的 C0/C1 验证。

首轮仅做 USB 接入和人工投屏。不要同时安装 Appium/UiAutomator2 等辅助服务，这样若大麦状态变化，才能定位发生在哪一步。真机身份不会因 USB 连接变成模拟器，但自动化行为仍需单独验收。
