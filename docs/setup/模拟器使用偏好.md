| 偏好 | 当前设置 | 启动时处理 |

| 本机键盘 | Mac 键盘输入启用，`hw.keyboard=yes` | 启动脚本检查配置；单击虚拟手机中的输入框后直接打字 |
| 屏幕键盘 | 接入硬件键盘时仍可显示 | 启动脚本设置，便于使用安卓中文输入法 |

## 启动方法

在访达中双击 `scripts/start-emulator.command`，或在终端运行：

```zsh
/Users/Admin/Desktop/work/Ticket/scripts/start-emulator.command
```

启动脚本使用项目内的 Android SDK 与虚拟设备，保留大麦 App 和现有设备数据，不会清空账号。运行日志在 `logs/emulator.log`（已忽略，不入 Git）。终端窗口在模拟器运行期间会保持打开。

本机键盘连接只传递按键；Mac 上中文输入法的候选窗不一定直接映射到安卓。需要输入中文时，优先使用安卓设备内的中文输入法。右侧栏导航按钮曾出现无响应，因此以**手机画面底部**的三键为准。

当前大麦登录页曾显示“亲，访问被拒绝”。键盘设置与此访问拒绝属于不同问题；登录排查记录见 `pagesamples/emulator-login.md`。
