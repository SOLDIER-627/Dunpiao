> **历史记录：**本地模拟器路线已于 2026-11-16 终止，SDK、镜像和 AVD 已删除。以下操作与路径不再可用；见 [归档说明](../../archive/emulator-2026-11-16/README.md)。

核对日期：2026-11-16。

## 推荐入口

- 腾讯应用宝“大麦”页面：https://sj.qq.com/appdetail/cn.damai
- 页面标注开发者和运营者为“北京大麦文化传媒发展有限公司”，安卓版本为 **9.0.38**（页面显示 2026-11-02 更新）。打开页面后选择**安卓版下载**；如页面要求通过应用宝安装，请按其官方流程操作。
- 大麦帮助中心“如何下载”：https://help.damai.cn/helpPage.htm?pageId=16 ，建议在应用市场搜索“大麦”。

本机当前安装的 `cn.damai` 也是 9.0.38，原安装文件是用户从未知网站获取。重新从正规应用商店获取**同版本**可排除 APK 来源问题，但不能证明或保证解除模拟器登录的“访问被拒绝”。

## 重装前后核对

1. 保留当前虚拟设备数据，不清空 AVD；不要在仓库中记录手机号、验证码或登录态。
2. 在应用宝页面确认名称“大麦”、开发者“北京大麦文化传媒发展有限公司”和版本 9.0.38。不要下载名称相似的“大麦国际 / MAISEAT”等其他应用。
3. 安装后查看应用能否正常打开；用户手动尝试登录一次。若仍显示“亲，访问被拒绝”，记录结果并停止重复尝试，说明 APK 来源不是充分解释。
4. 详细登录台账保存在忽略 Git 的 `pagesamples/emulator-login.md`。
