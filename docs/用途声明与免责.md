# 用途声明与免责

## 1. 用途

本项目是**个人学习与技术研究**项目，用于研究安卓 UI 自动化（uiautomator2）在真实 App 上的
工程实践。它只做一件事：**在你自己已登录的大麦账号上，替你自己完成几次重复点击**，把
「详情页 → 确定 → 提交」这几步做得比手快，然后停在付款页交给你。

适用场景：你本人已经决定要买某场演出的票，只是想减少手速造成的失败。

## 2. 明确不做的

- **不提供代抢服务**，不收费、不接单、不出售任何形式的抢票能力
- **不代解验证码**（滑块、点选、人机验证一律停止并交人工）
- **不做签名逆向 / 接口直调 / 协议破解**（不改包、不伪造设备指纹、不绕过风控）
- **不使用注入框架**（Frida / Xposed / 改机 / 代理池）
- **不自动支付**——付款永远由你本人在收银台手动完成
- **不做多账号、批量注册、养号、囤票转售**
- 不收集、不上传任何数据；脚本只在本机运行，不联网上报
