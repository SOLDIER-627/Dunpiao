# 真机连接与雷电云手机候选方案

> **当前方案：**本文件为早期对比设计，执行以 [USB 真机大麦方案](USB真机大麦方案_2026-11-16.md) 为准；雷电云路线已归档。


> **顺序更新（2026-11-16）：**用户决定先试雷电云手机，当前步骤与验收见 [雷电云专项方案](雷电云手机试用与Demo方案_2026-11-16.md)。本文保留实体真机路线供试验失败时使用。


更新：2026-11-16。对应 [调研](../research/真机与雷电云手机可行性调研_2026-11-16.md)和根目录 [TASKS](../../TASKS.md)。本方案是设计与验收口径，尚未连接真机、购买云手机或运行大麦自动化。

## 决策顺序

1. **设备可用性**：实体 Android 手机是否可供调试；大麦 App 人工登录是否成功。手机品牌不设限定，优先已有设备。
2. **连接可用性**：Mac 以 USB 接入真机，`adb devices -l` 确认唯一设备；如 USB 稳定，再评估无线调试。
3. **页面可读性**：人工在大麦打开非热门演出详情，验证截图、控件层级和弹窗状态；不触发真实订单。
4. **雷电云对照**：仅在需要云端持久在线或实体手机不可用时，做短期试用。先测人工登录，再核实正式 ADB/接口；两项都成功才考虑复用同一驱动。
5. **实现范围**：P0 为一账号、一设备、大麦优先；猫眼和多设备在 P0 通过后展开。

## 核心结构

```text
任务配置（无密码） → 调度/状态机 → 页面适配器（大麦；后续猫眼）
                               ↓
                         DeviceAdapter
                         ├─ USB/无线 ADB 真机（主线）
                         └─ 远程 ADB 云手机（仅 C0/C1 通过后）
                               ↓
                截图 + UI 层级 + 点击结果 + 断线状态
```

`DeviceAdapter` 接收显式设备序列号，提供 `health_check`、`screenshot`、`dump_hierarchy`、`tap`、`back`、`foreground_app`、`disconnect` 等能力。主线建议先用 ADB 与 openatx/uiautomator2 进行探测，再按参考仓库选择 Appium UiAutomator2 封装。具体依赖版本在接入时固定到锁文件。雷电云若没有 ADB，**不接入此接口**；其 PC 宏录制另做手动演示记录。

## 状态机与保护

- 状态：设备离线、App 未登录、演出详情、待开售、可购买、选择场次票档、确认信息、提交前、支付页、售罄、访问拒绝、未知。
- 每次页面动作后读取结果再转态；访问拒绝、登录失效、未知页面、设备断线立即停止。必须避免盲目连续点击或断线后自动重提。
- 票档若为图片文本，识别依次采用可读控件、带页面校验的位置、OCR；位置只在屏幕尺寸和页面版本已校验时有效。
- 配置包含演出 URL/ID、场次、票档、观演人昵称与张数、开始时间、最大尝试次数；不存账号密码、验证码或完整证件号。
- 默认只执行到**提交前确认**，展示场次、票价、张数和观演人供用户检查。真实下单单独启用，支付始终由用户完成；同一场次已有订单时停止。
- 日志只记录状态、时间、脱敏设备号、错误码和耗时；截图与 UI dump 可能含私人信息，保存在忽略 Git 的本地目录，分享前脱敏。

## P0 分阶段验收

| 阶段 | 产物 | 验收条件 |
|---|---|---|
| D0 真机接入 | 设备记录与连接诊断 | 手机人工登录成功；USB 授权后 `adb devices -l` 在线；Mac 可人工查看屏幕 |
| D1 页面采样 | 大麦各关键页面的脱敏截图、层级与状态标注 | 详情、选票、确认、支付入口、售罄、弹窗、拒绝/登录失效至少可识别或明确标成不可读 |
| D2 只读 Demo | 本地 CLI、配置模板、状态检测 | 不点击下单；可暂停、设备断线安全结束；同一页面重复运行结果一致 |
| D3 模拟流程 | 有限动作的非热门演出流程 | 经用户目视核对，能从详情到提交前；错误状态不越过提交闸门 |
| D4 真实订单验证 | 单次人工监督的实际结果记录 | 如平台允许且用户选择验证：最多一次有效订单，停在支付页，用户决定付款 |
| C0/C1 云端候选 | 雷电云登录记录与 ADB/接口证据 | 两项均通过才纳入 `DeviceAdapter`；否则记录为 PC 人工候选 |

## 依赖与实施取舍

- Mac 只需官方 Android Platform-Tools。装 scrcpy 用于人机交接；安装 Appium/UiAutomator2 前先确认设备连接。**不下载 Android 镜像，不恢复本地 AVD。**
- 真机可能因线缆、授权、系统省电或厂商限制断连。启动前做设备健康检查，执行中对离线直接安全停止。首次连接由用户在手机上点授权。
- 雷电云增加网络往返、客户端窗口与云端隐私依赖；关键不是“看上去像真机”，而是 App 登录、页面读取、断线恢复是否可验证。没有官方 ADB 接入或实测，不编写任何假设连接器。
- 不编写验证码代解、设备指纹伪装、签名逆向、代理池或自动支付；认证和支付交给用户。

## 下一次执行窗口

用户提供或连接一台可调试的安卓手机时，先执行 [真机连接验证清单](../setup/真机连接验证清单.md)。若先选择雷电云，则先获得短期试用与官方对 ADB 的明确答复，再开始 C0/C1。两条路线的技术验证记录相互独立，不能用截图推断云手机的自动化可行性。
