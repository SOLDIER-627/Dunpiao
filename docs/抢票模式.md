# 抢票模式（开售准点）

入口：`scripts/rush.py`　｜　原理细节：[原理与流程](原理与流程.md)

## 一句话

开售前在详情页待命，T0 准点直点购票 CTA，然后「确定 → 立即提交」两下，停在收银台，**付款人工**。

## 前置准备（人工，开售前完成）

1. 大麦 App 内完成**预约 + 预选**：目标场次 + 票档（如「11.21 周六场 看台 588」）
2. 实名观演人已在 App 内配置好（脚本只勾选、不新增）
3. 手机停在目标演出**详情页**
4. 预填坐标（预约态即可，只信 CTA）：

```bash
.venv/bin/python scripts/rush.py --capture-coords --show-tag <show_tag>
```

预选生效后，开售时面板打开即目标档，脚本只需 3 次点击：

```
① CTA（详情页购票按钮）  ② 确定（SKU 面板）  ③ 立即提交（订单页）
                          第 4 步：付款——永远人工
```

## 命令

```bash
# 演练（不提交，~2s，停在提交前核对）
.venv/bin/python scripts/rush.py --show-tag <tag> --expected-total 588.00

# 开抢（T0 准点直击）
.venv/bin/python scripts/rush.py --wait-open 15:00 --submit \
    --show-tag <tag> --expected-total 488.00

# 指定日期时刻（跨天/明确日期时更安全）
.venv/bin/python scripts/rush.py --wait-open "2026-12-06 12:00" --submit ...

# 人工取消订单后闭环审计记录
.venv/bin/python scripts/rush.py --clear-record --show-tag <tag>
```

## 命令速查

| 参数 | 作用 |
|---|---|
| `--wait-open HH:MM`（或 `YYYY-MM-DD HH:MM`） | 开售等待：T0 准点直击（时钟 severe 默认拒绝） |
| `--countdown-lead-ms 3000` | T0 前多少毫秒进入 prewarm 窗口（上游默认 3000） |
| `--submit` | 真实提交（默认关闭；核对全过才点，单次不盲重试） |
| `--preselect` / `--no-preselect` | 预选直点默认**开**；未做预约预选的演出加 `--no-preselect` |
| `--capture-coords` | 测量模式：预约态取坐标写缓存即停 |
| `--expected-total 488.00` | 订单金额核对基准（**每场必改**） |
| `--show-tag <tag>` | 缓存键 / 审计标识 |
| `--expect-session-date 2026.11.21` | 订单页场次护栏（多场次同价位时建议加） |
| `--clear-record` | 审计标记（不拦截提交） |
| `--ignore-clock-trust` | 时钟 severe 时强行继续（默认拒绝） |

## 开售等待的内部行为

```
clock_sync 采样（Mac SNTP + 设备双采样）→ 信任分级（severe 默认拒绝）
  → 单调时钟 deadline（不受系统改时间影响）
  → 剩余 > lead：0.05s 粒度倒计时
  → 剩余 ≤ lead（默认 3s）：prewarm 快照（CTA 可见性 + 像素亮橙 + 文案护栏，只侦察不点击）
  → T0：最后一道廉价闸门（activity 仍是详情页）→ 直点 CTA（~45ms）
  → 点击后立刻入口轮询（0.45-3s），从不假设点击成功
```

prewarm 三项任一不过 → 放弃直点，降级为「缓存坐标 → 文案护栏 → 入口轮询」验证路径。

## 耗时基准（真机实测，Xiaomi 14 / HyperOS）

| 分段 | 实测 |
|---|---|
| T0 直点 CTA 偏差 | ~1-45ms |
| CTA → 面板打开 | 0.15-0.30s |
| 驻留 + 首批连点 | 0.4s + 0.9s 窗口内命中 |
| 预选生效：T0 → 订单确认页 | ~1.0s（未命中预选时 ~2.5s） |
| 提交 → 收银台 | 2.78s（大麦建单地板，不可优化） |

每次运行结束打印「=== 耗时明细 ===」（t+ 相对 CTA 点击、步长）。

## 常见 STOP

| STOP | 原因 | 处置 |
|---|---|---|
| 不在详情页 | 手机不在目标演出详情页 | 手动导航后重跑 |
| CTA 文案护栏拦截 | 预约/预售态文案 | 属预期，开售后自动放行 |
| 确认页未出现 | 无票/预约态/弹窗拦截 | 看屏幕确认 |
| 时钟信任 severe | 时钟未同步 | 同步后重跑（或 `--ignore-clock-trust`） |
| 核对未全通过 | 金额/张数/观演人不符 | 按日志 `s3: 订单核对 {...}` 逐项查 |
| 提交后未检测到收银台 | 大麦「提交中」慢 / 弹窗挂屏 | 人工点「继续尝试」或查「我的→待付款」 |
