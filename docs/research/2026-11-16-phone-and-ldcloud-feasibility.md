# 电脑连接安卓真机与雷电云手机：可行性调研

> **顺序更新（2026-11-16）：**用户决定先实际试用雷电云手机。下文的“真机优先”为前一轮技术建议，当前执行顺序以 [雷电云专项方案](../architecture/2026-11-16-ldcloud-trial-plan.md) 为准。


更新：2026-11-16。目标是为大麦先行、猫眼随后的一台设备 MVP 选定运行载体。本文区分已核实事实、推断与待实测项。**雷电云手机是云端虚拟 Android 设备，不是 USB 真机。**截图能说明代抢者使用其 PC 客户端展示订单，不能证明其大麦登录、下单或外部脚本接入方式；见 [截图设备识别记录](../../调研_代抢截图设备识别_2026-11-16.md)。

## 1. 本机与旧路线事实

- 旧本地 AVD Android 15 ARM64 能运行大麦 App，但在获取短信验证码之前显示“亲，访问被拒绝”；同一虚拟机内网页版能登录。该结果不能单独确定具体安全校验字段，也不能推广到所有云手机。
- 本地模拟器及镜像已删除并归档，旧任务作历史资料。当前 Mac 上没有检测到 `adb`、`scrcpy` 或 Appium 可执行文件，也没有检测到已连接的安卓设备。现有 Python 3 与 Node.js；不需要再安装系统镜像。
- 用户已明确指定：优先考虑电脑连接安卓真机，同时评估雷电云手机；第一版大麦，之后猫眼。

## 2. 候选路线与证据

| 路线 | 已核实能力 | 关键未验证项 | 建议 |
|---|---|---|---|
| USB 安卓真机 + Mac | Android 官方支持 USB 调试、授权后通过 `adb devices` 识别；scrcpy 官方支持 macOS 上镜像与键鼠操作；UiAutomator2 支持真实设备 | 用户手头是否有可用 Android 手机；该手机大麦 App 能否正常登录和展示目标页面 | **主线**，先做只读接入与人工登录验证 |
| 同局域网无线调试真机 | Android 11+ 官方支持无线调试配对；scrcpy 通过 ADB 使用同一设备 | Wi-Fi 稳定性、配对权限、延迟 | USB 跑通后的便利方案，不作为首轮唯一连接 |
| 雷电云手机 PC 客户端 | 官网提供 Apple 芯片 macOS 客户端；官方文档确认远程控制、安装应用、截图、键盘映射、宏录制 | 大麦 App 是否可登录和正常使用；普通用户是否能获得 ADB 连接；Mac 版是否有全部所需功能；网络延迟与服务稳定性 | **有条件候选**：先短期试用与能力验证，不能当作真机等效物 |
| 雷电云手机 PC 宏录制 | 官方确认 PC 端能录制、导入导出、循环播放固定操作 | 能否可靠识别票档变化、登录失效、售罄、弹窗；能否安全停止 | 仅适合低风险重复演示，不作为订单状态机实现基础 |
| 其他明确开放 ADB 的云手机 | 火山引擎、华为云等官方文档说明云端 ADB 接入方式 | 产品资格、费用、该平台对票务 App 的兼容性 | 雷电云若无 ADB 时，作为技术对照；不表示已选型或已购买 |

## 3. 真机主线的技术依据

1. [Android 官方 ADB 文档](https://developer.android.com/tools/adb)要求在手机开发者选项开启 USB 调试、在手机上确认该电脑的 RSA 授权，再用 `adb devices` 检查。Android 11+ 可通过同一网络的无线调试配对；连接成功仍应由用户在手机上管理授权。
2. [Android 官方设备运行指南](https://developer.android.com/studio/run/device/)描述 USB 与 Wi-Fi 两种连接。Mac 不需要 Windows 专用 USB 驱动。只需下载 [官方 Platform-Tools](https://developer.android.com/tools/releases/platform-tools) 中的 `adb`；不需要重建已删除的 AVD/系统镜像。
3. [scrcpy 官方仓库](https://github.com/Genymobile/scrcpy)和 [macOS 安装说明](https://github.com/Genymobile/scrcpy/blob/master/doc/macos.md)确认其通过 ADB 镜像和键鼠控制真实 Android 设备，且无需 root。它负责人工查看与接管，不替代页面状态识别。
4. [Appium UiAutomator2 驱动文档](https://github.com/appium/appium-uiautomator2-driver)说明真实设备需显示在 `adb devices -l`，可用 `udid` 锁定设备；驱动会在设备上运行辅助服务。版本兼容性应在安装时按当期文档核对，不照搬旧仓库的版本号。
5. [openatx/uiautomator2](https://github.com/openatx/uiautomator2)给出真机经 ADB 连接、按序列号选择设备、读取页面信息的示例。它适合第一阶段页面采样；Appium 适合与参考仓库代码结构对齐。
6. [WECENG/ticket-purchase issue #14](https://github.com/WECENG/ticket-purchase/issues/14)中作者明确回答 App 路线可连接真实设备，通过 USB 或同一网络使用 ADB，不要求模拟器。[issue #75](https://github.com/WECENG/ticket-purchase/issues/75)的贡献者也说明自己用手机插 USB；这属于开源项目实践，不能证明本项目的账号或场次必然可下单。
7. [HaTickets 官方 README](https://github.com/currycan/HaTickets) 当前将 Android 12–14 实体手机列为 Mobile 路线前提，并把桌面/Web 方案标为不可用；这是该开源项目对自己代码的适用范围声明，支持优先验证真机，不等于大麦官方保证任何真机均可下单。其推荐 Python 3.10–3.13，后续依赖安装需按选定实现重新核实。
8. [Lzhimie/damai-ticket-helper README](https://github.com/Lzhimie/damai-ticket-helper)提供真机 USB 调试与 Appium 环境检查流程，并注明需先在大麦 App 人工登录。代码和页面逻辑可参考，实际可用性仍需本机验证。

## 4. 雷电云手机：官方已确认与尚无证据

- [官网](https://www.ldyuncs.com/)提供 Apple 芯片 macOS 下载入口；这是电脑上的**云手机控制客户端**，不代表连接了一部本地实体手机。
- [PC 设备界面说明](https://www.ldyuncs.com/course/104532)明确有返回、桌面、最近任务、安装应用、截图、剪切板及设备切换等功能，与用户给出的订单照片旁栏相符。
- [PC 宏录制指南](https://www.ldyuncs.com/course/107288)确认可录制并回放固定动作、设置次数和间隔；它未证明可读取大麦页面状态或提供第三方程序接口。
- [套餐和系统说明](https://www.ldyuncs.com/course/101008)显示不同套餐对应 Android 版本，实际规格以产品当时页面为准。产品价格、试用时长、可选版本会变，不应写死预算。
- 在本次检索的雷电云公开资料中，**未找到面向普通用户的远程 ADB 接入说明或公开 API**。这是资料缺口，不等于证明绝对不支持。需向官方客服询问 Mac 客户端账号是否能获得 ADB 地址/端口及授权方式；未证实前不能按 Appium 方案承诺接入。
- 云手机与实体手机的运行环境、网络出口和风控表现可能不同。订单截图只能证明某人在云手机画面中展示了订单，不足以证明该订单由云手机自动下单，亦不能保证本账号可登录。

## 5. 比较实验与停止条件

| 验证序号 | 设备 | 操作 | 通过标准 | 失败后的处理 |
|---|---|---|---|---|
| P0 | 实体 Android 真机 | 手机用户自己从可信商店安装大麦并手动登录 | 手机端可正常登录、打开演出详情 | 记录准确报错、时间、App 与系统版本，停止自动化接入 |
| P1 | 同一真机 | 开启 USB 调试、授权 Mac，执行只读设备检查 | `adb devices -l` 显示一台 `device` | 检查数据线、USB 模式、授权提示；不刷机、不 root |
| P2 | 同一真机 | scrcpy 人工查看；采集已脱敏的截图与 UI 层级 | 能看到正确页面、能人工接管 | 记录无法识别的控件，采用视觉识别或人工步骤 |
| C0 | 雷电云 | 短期试用、官方客户端中手动安装和登录大麦 | 登录和浏览目标页面均成功 | 若重现“访问被拒绝”，停止购票自动化评估 |
| C1 | 雷电云 | 官方客服/产品文档核实 ADB 或正式自动化接口 | 有可复现的连接步骤、授权方式，Mac `adb devices -l` 可见 | 若无接口，只保留人工客户端或明确受限的宏演示方案 |
| C2 | 雷电云 | 在 C0/C1 成功后测截图、层级读取、延迟和断线恢复 | 状态可读、可中止、断线不重复提交 | 未达标不进入订单流程 |

验证只用自有账号。短信、人脸等认证由用户本人完成；不在代码或文档中保存凭据。一次拒绝访问应记录后停止，不做高频重复登录。购票阶段另外验证“实际下单可行性”；登录成功并不代表下单成功。

## 6. 选型结论

**优先准备一台实体 Android 手机，以 USB ADB 打通可观察、可中止的单账号流程。**雷电云手机保留为第二候选，但必须先通过 App 登录和自动化接入两道关口。若缺少远程 ADB，使用 PC 客户端只能做人工操作或有限宏演示，不能直接复用基于 UiAutomator2 的页面状态机。当前不购买套餐、不安装客户端；先核实功能和用户可用设备。
